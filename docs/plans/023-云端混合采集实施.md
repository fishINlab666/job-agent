# Cloud Hybrid Collection Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在 Cloudflare Python Worker + D1 上运行现有五个公开招聘源，形成云端唯一采集真源并立即完成首轮技术采集。

**Architecture:** 现有 Python Adapter 保持唯一解析实现，并新增异步网络入口；构建脚本把经过 allowlist 的共用源码复制进 Worker 临时构建目录。Worker 以窗口状态机编排五源，D1 原子保存窗口、运行、岗位当前版本和递增变化游标；HTTP 写入口使用 Cloudflare Secret 鉴权。

**Tech Stack:** Python 3.13、httpx AsyncClient、Cloudflare Python Workers、Cron Triggers、D1、pytest、pywrangler、Wrangler 4。

```python
async def fetch_async(self) -> list[RawJob]:
    self.empty_is_authoritative = False
    self.skipped_no_id = 0
    rows: list[dict] = []
    cursor = self._initial_cursor()
    async with httpx.AsyncClient(timeout=self.timeout, headers=self._headers()) as client:
        while True:
            response = await client.post(self._search_url(), json=self._page_payload(cursor))
            response.raise_for_status()
            page = self._decode_page(response, cursor=cursor, fetched=len(rows))
            if page.authoritative_empty:
                self.empty_is_authoritative = True
                return []
            rows.extend(page.rows)
            if page.complete:
                break
            cursor = page.next_cursor
    return self._jobs_from_rows(rows)
```

def active_window(now_utc: datetime) -> Window | None:

## Gate 与停止条件

- Cloudflare 未登录：只停部署，保留已测试本地候选。
- 免费层 CPU/size/subrequest 超限：记录真实限制；不得自动开通付费或改为复制规则的
  TypeScript 重写。付费是新的消费授权边界。
- 任一真实源返回结构与 fixture 不一致：单源失败并保留响应类别，不把半截结果写成功。
- 任何 secret、profile、application、cookie 或本机绝对路径进入 bundle：BLOCK。
- 真实首轮只读采集可以写 D1 公开岗位事实，但不得触碰源站投递接口、登录态或本机申请库。
