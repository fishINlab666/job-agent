## 🔍 技术术语处理原则

### 保留英文的情况（符合中文技术文档习惯）
1. **专有名词**：Playwright, Chromium, SQLite, Pydantic
2. **技术术语**：Protocol, CLI, API, HTTP, JSON
3. **命令/函数名**：`apply`, `sync`, `digest`, `_fill_form`
4. **文件路径**：`jobagent/submitters/base.py`
5. **Git 相关**：commit, push, PR
6. **代码标识符**：变量名、类名、函数名（Python 规范）

### 完全中文的内容
1. **用户界面**：所有面向用户的提示、错误消息
2. **文档标题**：章节标题、文档名
3. **功能描述**：对功能的解释说明
4. **注释**：代码注释、配置注释
5. **帮助文本**：CLI 帮助信息
